What is Linux Media Downloader?

A desktop app for saving YouTube media (audio or video, single tracks or whole playlists) for personal use. It uses yt-dlp to download and ffmpeg to convert/split. It runs as its own window (app.py) or in a browser (browser_app.py).

How does "Split Multi-Chapter video" work?

Some long videos (full albums, mixes, compilations) are actually many tracks in one video. With this option checked:

  1. The app downloads the single video locally first (as one audio/video file).
  2. It then reads the track boundaries — from the video's embedded chapters if present, otherwise from a timestamped tracklist in the description.
  3. It splits that file into one file per track using ffmpeg, and places them in a new folder named after the video (ending in _playlist).
  4. The original single file is removed, leaving just the individual tracks — which then show up automatically under Playlists and File Manager.

If a track has a chapter title, that becomes the filename; if a chapter has no title, the file is named with a sequence number plus the video's title (e.g. 03_Best_Of_The_80s.mp3). If the video has no chapters and no tracklist, nothing is split and the whole file is kept.

The pages (sidebar)

Text operations (Playlists & File Manager)

These rename or tidy your files in bulk. Every rename keeps names unique (a short salt is added on a clash), and everything is undoable (Delete moves files to a .trash folder you can empty later).
